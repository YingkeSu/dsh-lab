# dsh-lab plugin index

A format-1 [DSH plugin index](https://github.com/deepseek-ai/deepseek-harness/blob/main/docs/user/guide/plugin-market.md)
for the plugins maintained in this repository: `index.json` plus inline icons,
generated by DSH's reference generator and validated by `dsh-plugin-market-index`.

## Use it

In DSH, enable the experimental **custom plugin index** bundle, open
**Plugins → Discover**, choose **Add index source**, and paste:

```text
https://raw.githubusercontent.com/YingkeSu/dsh-lab/main/market/index.json
```

## Regenerate

The source list is [plugins.txt](plugins.txt), one npm package name per line.
From a DSH source checkout:

```sh
pnpm --filter @deepseek-ai/dsh-plugin-market-generator start \
  --input <path-to-this-repo>/market/plugins.txt \
  --output <path-to-this-repo>/market/index.json \
  --title "dsh-lab plugins" \
  --description "Plugins maintained in the dsh-lab repository"
```

The generator downloads only package metadata and tarballs; it never installs
or runs the listed plugins. Its cache (`.plugin-market-cache/`) is ignored.
